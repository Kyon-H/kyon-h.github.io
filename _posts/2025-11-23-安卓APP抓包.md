## 2. 证书配置

### 2.1. 生成 `.0` 证书

Repable 可直接导出证书，yakit 可通过以下命令生成

```shell
# PEM文本格式
openssl x509 -in yakit.cer -out cacert.pem
# DER二进制格式
openssl x509 -inform DER -in yakit.cer -out cacert.pem
# 获取hash
openssl x509 -subject_hash_old -in cacert.pem |head -n 1 #cdfb61bc
mv cacert.pem cdfb61bc.0
```

移动到 `/system/etc/security/cacerts/` 目录
## 3. 安装 ADB

```shell
# 查看设备
adb devices
# 连接设备
adb -s <设备名称> shell
# 切换到root用户
su
# 设置文件权限
chmod 644 /system/etc/security/cacerts/cdfb61bc.0
```

若无写权限，模拟器无修改权限选项，需重新挂载添加写入权限

```shell
cat /proc/mounts
mount -o rw,remount /
mv /sdcard/Download/cdfb61bc.0 /system/etc/security/cacerts
```
